| **1. COURSE INFORMATION** |  |  |  |  |  |  |  |
| 1. | Course includes all [CU Syllabi Requirements](https://www.cedarville.edu/cf/processSAMLresponse.cfm) including:<br><br>- Contact information (instructor and department/school)<br>- Support Services (technical, tutoring, accommodations)<br>- Academic Integrity<br>- Filing grievances<br>- Instructor/Facilitator interaction guidelines |  |  |  |  |  |  |
| 2. | Clear overviews and structure are provided at the course and module level. |  |  |  |  |  |  |
| 3. | Syllabus provides clear course expectations including technical requirements. |  |  |  |  |  |  |
| 4. | Course objectives are clearly defined, measurable, level appropriate, and aligned to learning activities and assessments. |  |  |  |  |  |  |
| **2. COURSE TECHNOLOGY AND TOOLS** |  |  |  |  |  |  |  |
| 5. | Requisite skills for using technology tools (websites, software, and hardware) are clearly stated, scaffolded in a timely manner, and supported with resources. |  |  |  |  |  |  |
| 6. | Frequently used technology tools can be easily accessed. Any tools not being utilized are removed from the course menu. |  |  |  |  |  |  |
| 7. | Course includes links to privacy policies for technology tools. |  |  |  |  |  |  |
| 8. | Any technology tools meet accessibility standards. |  |  |  |  |  |  |
| **3. DESIGN, LAYOUT, AND ACCESSIBILITY** |  |  |  |  |  |  |  |
| 9. | A logical, consistent, and uncluttered layout is established. The course is easy to navigate (consistent color scheme and icon layout, related content organized together, self-evident titles). |  |  |  |  |  |  |
| 10. | Large blocks of information are divided into manageable sections with ample white space around and between the blocks. |  |  |  |  |  |  |
| 11. | There is enough contrast between text and background for the content to be easily viewed. |  |  |  |  |  |  |
| 12. | Instructions are provided and well written. |  |  |  |  |  |  |
| 13. | Course is free of grammatical and spelling errors. |  |  |  |  |  |  |
| 14. | Text is formatted with titles, headings, and other styles to enhance readability and improve the structure of the document. |  |  |  |  |  |  |
| 15. | Flashing or blinking and red or green text are avoided. |  |  |  |  |  |  |
| 16. | A sans-serif font with a standard size of at least 12 pt is used. |  |  |  |  |  |  |
| 17. | Tables meet CU accessibility standards. [Need Link] |  |  |  |  |  |  |
| 18. | Slideshows use a predefined slide layout and include unique slide titles. |  |  |  |  |  |  |
| 19. | For all slideshows, there are simple, non-automatic transitions between slides. |  |  |  |  |  |  |
| 20. | Text content is available in an easily accessed format, preferably HTML. All text content is readable by assistive technology, including a PDF or any text contained in an image. |  |  |  |  |  |  |
| 21. | A text equivalent for every non-text element is provided ("alt" tags, captions, transcripts, etc.), and audio description is provided for video-only content. |  |  |  |  |  |  |
| 22. | Text, graphics, and images are understandable when viewed without color. Text should be used as a primary method for delivering information when possible. |  |  |  |  |  |  |
| 23. | Hyperlink text is descriptive and makes sense when out of context (avoid using "click here"). |  |  |  |  |  |  |
| **4. CONTENT AND ACTIVITIES** |  |  |  |  |  |  |  |
| 24. | Course offers access to a variety of engaging resources to present content, support learning and collaboration, foster biblical integration, and facilitate regular and substantive interaction with the instructor. |  |  |  |  |  |  |
| 26. | Course provides activities for learners to develop higher-order thinking and problem-solving skills, such as critical reflection and analysis. |  |  |  |  |  |  |
| 27. | Course materials and resources include copyright and licensing status, clearly stating permission to share where applicable. |  |  |  |  |  |  |
| **5. INTERACTION** |  |  |  |  |  |  |  |
| 28. | Regular and substantive instructor-to-student expectations, and predictable or scheduled interactions and feedback, are present, appropriate for the course length and structure. |  |  |  |  |  |  |
| 29. | Expectations for all course interactions (instructor to student, student to student, student to instructor) are clearly stated and modeled in all course interaction and communication channels. |  |  |  |  |  |  |
| 30. | Learners have an opportunity to get to know the instructor. |  |  |  |  |  |  |
| 31. | Course provides activities intended to build a sense of class community, support open communication, promote regular and substantive interaction, and establish trust (e.g., ice-breaking activities, Course Bulletin Board, planned Office Hours, and dedicated discussion forums). |  |  |  |  |  |  |
| 32. | Course offers opportunities for learner-to-learner interaction and constructive collaboration. |  |  |  |  |  |  |
| 33. | Courses provide guidance and opportunities for students to share what they are learning and helpful resources to promote intellectual and spiritual growth. |  |  |  |  |  |  |
| **6. ASSESSMENT & FEEDBACK** |  |  |  |  |  |  |  |
| 34. | Course grading policies, including consequences of late submissions, are clearly stated in the Course Information/Syllabus materials. |  |  |  |  |  |  |
| 35. | Course includes frequent, appropriate, and authentic methods to assess the learners' mastery of content. |  |  |  |  |  |  |
| 36. | Criteria for the assessment of a graded assignment are clearly articulated (e.g., rubrics, exemplary work, etc.). |  |  |  |  |  |  |
| 37. | Course provides opportunities for learners to review their performance and assess their own learning throughout the course (via pre-tests, self-tests with feedback, reflective assignments, peer assessment, etc.). |  |  |  |  |  |  |
| 38. | Learners are informed when a timed response is required. Proper lead time is provided to ensure there is an opportunity to prepare accommodation. |  |  |  |  |  |  |
| 39. | Course includes the opportunity for learners to provide descriptive feedback on their experience in the online course, the course design, content, user experience, and technology. |  |  |  |  |  |  |
| **7. CHRISTIAN PERSPECTIVE** |  |  |  |  |  |  |  |
| 40. | Course demonstrates effort to approach the content from a Christian perspective. |  |  |  |  |  |  |
| 41. | Scripture is appropriately referenced in the course materials. |  |  |  |  |  |  |
| 42. | Questions are surfaced and engaged related to challenges from those outside the faith, as appropriate. |  |  |  |  |  |  |
| 43. | Students are challenged to consider content from a Christian perspective and respond biblically to the things being learned. |  |  |  |  |  |  |
